# Submission checklist — complete before sending

- [ ] Successful clean install, type check and production build.
- [ ] Real runtime migration applied and seeded sample data visible.
- [ ] Desktop and mobile customer flow tested.
- [ ] Database-backed availability and collision rejection verified on live app.
- [ ] Admin status, reschedule/cancel and invoice PDF tested.
- [ ] Gemini key configured privately and real multilingual tests recorded.
- [ ] Final prompt iteration note reflects an actual observed model failure/retest.
- [ ] GitHub URL exists and reviewer has access.
- [ ] Live URL opens for the reviewer and includes frontend/backend/chatbot.
- [ ] Hosted DB read access arranged without publishing a write credential.
- [ ] Cold-start behavior measured; if the chosen host sleeps, mention its observed delay.
- [ ] 2–3 minute video recorded by the candidate, with no secrets visible.
- [ ] system-prompt.txt and prompt-iteration-note.md included.

Submission fields to fill: candidate name, GitHub URL, live URL, video URL, safe reviewer access instructions, any host limitations. Do not send placeholders as completed deliverables.
